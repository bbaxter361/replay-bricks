✨ What Is Compass?

Compass is your all-in-one activities dashboard. It helps you manage the Assisted Living and Memory Care calendars, track resident contacts, ask your AI assistant Spring for activity ideas, log the books you're reading, and export your calendar to PDF, CSV, or Canva.

📅 Calendar

Plan activities for Memory Care, Assisted Living, or both. Switch between month, week, and day views.

  • View by wing — Use the filter dropdown to show "Both Calendars", "Assisted Living", or "Memory Care".
  • Add an event — Click + Add Event, fill in the title, date/time, activity type, wing, and residents.
  • Activity types — Music 🎵, Art 🎨, Exercise 🏋️, Games 🎮, Outings 🌳, Therapy 💆, or Custom ✨. Each has its own color.
  • Click an event — See full details, add or remove residents, change the time or wing.
  • Export — Hover "Export" to download as PDF, CSV, iCal, or push events to Canva ✨ for a beautiful print calendar.
💡 Tip: When viewing "Both Calendars", events are color-coded by wing — blue for Assisted Living, violet for Memory Care. When filtered to one wing, you'll see activity-type colors instead.

👥 Contacts

Keep track of residents, family members, doctors, and staff — all searchable with tags and notes.

🔍 Search & Filter

Search by name, tag, phone number, or notes. Filter the list by relationship type: Resident, Family, Doctor, or Staff.

🏷️ Tags

Add descriptive tags like music-lover, morning-person, needs-quiet to quickly group residents by preference.

📝 Notes

Record each resident's preferences, triggers, and activity history so you always know what works best for them.

🤖 AI Chat — Spring

Spring is your AI-powered activities planning assistant. She's an expert in memory care, Montessori methods, exercise programs, art projects, and more. She can schedule events and add books directly from your conversation.

💬 Ask Anything

Try: "What's a good 30-minute music activity for 6 memory care residents with late-stage Alzheimer's?"

📅 Create Events

Say: "Schedule chair yoga for assisted living tomorrow at 10am with Mildred and George." Spring adds it to the calendar.

🖼️ Share Images

Upload a photo of your supply closet or art materials — Spring can suggest activities based on what you have.

📚 Add Books

Tell her: "Spring, add 'Dune' by Frank Herbert, 412 pages." It shows up on your Books page.

  • Click AI Chat in the sidebar.
  • Type your message or pick a suggested prompt.
  • Spring replies with detailed, practical activity suggestions.
  • If you asked for an event or book, Spring adds it automatically and confirms.
⚠️ Server Required: The chat feature needs the Compass API server running:
cd compass && node server.js
The server runs on port 3001 and connects to DeepSeek AI.

📚 Books — Your Reading Tracker

Track every book you finish. See your total pages read this week, this month, and this year at a glance.

➕ Add Manually

Click "Add New Book" on the Books page, enter the title, author, and page count.

🤖 Add via Spring

In the AI Chat, just tell Spring to add a book and she'll handle it.

📊 Stats Dashboard

Four stat cards show: This Week, This Month, This Year pages, and Total Books finished.

🎮 Games & Activities

🚀 Running the App

cd compass
npm install
npm run dev        # Starts the web app on http://localhost:5174
node server.js     # (separate terminal) Starts the AI chat API server

All your data lives in your browser — nothing is sent anywhere except your chat messages to DeepSeek via the local API server.
