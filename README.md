# Replay Bricks — Monorepo

**Same Bricks, New Stories.** 

This monorepo contains all projects for Replay Bricks.

## Projects

### 1. replaybrick.com — Website Redesign
Modern, professional LEGO storefront website. Located in `/website/`.

Built with Vite + React 19 + Tailwind CSS v4 + Framer Motion. See `/website/README.md` for details.

**Quick start:**
```bash
cd website
npm install
npm run dev      # development
npm run build    # production build → dist/
```

### 2. Amanda's Memory Care App (Codename: "Compass")
AI-powered activities director app with custom calendar, contacts database, and business card OCR. Located in `/compass/`.

### 3. Bricqer Replacement (Codename: "Hold") 
Private inventory management system syncing BrickLink, Brick Owl, and eBay — replaces $50/mo Bricqer subscription. Located in `/hold/`.
